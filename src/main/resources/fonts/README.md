# Fuente de reportes

Noto Sans Regular, distribuida bajo SIL Open Font License 1.1. La licencia completa está en OFL.txt. Se incorpora en PDF para representar español, inglés y portugués sin depender de fuentes instaladas en el servidor.

Origen oficial: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Los caracteres fuera de la cobertura se representan mediante su código Unicode; no se sustituyen silenciosamente por otro carácter. Los archivos Excel conservan el texto Unicode original.
